# Требования и запуск

## Системные требования
* **ОС**: Windows 10
* **Среда выполнения**: Deno 2.7.13
* **Расположение**: Все файлы должны находиться в одной директории

## Запуск приложения
Выполните команду в терминале из папки с проектом:

```bash
.\deno.exe run --allow-net --allow-write --allow-read .\main.ts
```
